# 指标口径

| 指标 | 定义 | 备注 |
|---|---|---|
| 总订单数 | `COUNT(DISTINCT order_id)` | 包含所有状态 |
| 成交订单数 | 状态为 `delivered` 的订单数 | 作为已完成交易口径 |
| 成交额 | 成交订单的 `SUM(price)` | 不含运费，不等同财务收入 |
| 客单价 | 成交额 ÷ 成交订单数 | 订单级 |
| 件单价 | 成交额 ÷ 成交商品件数 | 商品行级 |
| 取消率 | `canceled` 订单数 ÷ 总订单数 | `unavailable` 单独展示 |
| 活跃购买顾客数 | 至少有一笔成交订单的 `customer_unique_id` 数 | 顾客级 |
| 复购顾客数 | 至少有两笔成交订单的顾客数 | 顾客级 |
| 复购率 | 复购顾客数 ÷ 活跃购买顾客数 | 数据窗口内复购 |
| 准时送达率 | 实际送达时间 ≤ 预计送达时间 | 仅完整送达记录 |
| 平均履约时长 | 实际送达时间 − 下单时间 | 单位为天 |
| 平均提前天数 | 预计送达时间 − 实际送达时间 | 负数代表延迟 |
| 低评分率 | 评分 ≤ 2 的订单数 ÷ 有评分订单数 | 订单级 |
| 同期群留存率 | 某月仍购买的同期群顾客数 ÷ 首购月顾客数 | 自然月口径 |

## 月度趋势注意事项

原始数据首月和末月可能不是完整自然月。趋势图保留所有月份，但报告与同比、环比结论应优先使用完整月份，并明确标注观察窗口。
